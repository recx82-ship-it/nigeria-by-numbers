Nigeria by Numbers — a national statistics site for Nigeria: population and demographics, the economy, all 36 states and the FCT, health and education. Every figure is a published official statistic, labelled with its source and year. It runs in a browser from static files with no network request, on desktop and phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `app/index.html` directly from any static server with `app/` at its root.
