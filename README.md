Nigeria by Numbers — a national statistics explorer for Nigeria: population, economy, states, health and education, every figure labelled with its publisher and year. Static files, no network at runtime, no libraries, all data embedded. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — overview, population, economy, states, health & education, and sources pages on hash routes.
